# ESP32-Drone-ESP-C6-FLY_Final
This is a project, built from ESP32-C6, a drone that supports BLE&WIFI control                   
More info is given in the Word doc. (the one labled "DOCUMENT")                                     
If you are willing to just get one of these original ones, you can put the zip (that"GerberFileForManufaturing")                        
and place an order from PCBWay, JLCPCB, or other.There is NO NEED TO UNZIP IT if you do it this way.                                          
However, if you want to change this project in to your own, it is recommended to use the KiCAD files                                 
(_SCH is schematic,_PRO is the whole project, _PCB is the final PCB layout)                                        
Have fun building!
